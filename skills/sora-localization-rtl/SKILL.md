# Sora Localization & RTL

Design to survive:
- Arabic and RTL;
- longer translations;
- mixed RTL/LTR content;
- multi-line labels;
- text scaling;
- locale-specific dates/numbers/currency.

Check:
- directional padding/alignment;
- back/forward icons;
- chevrons/arrows;
- row ordering;
- form alignment;
- truncation;
- hardcoded widths;
- mixed phone/email/URL strings.

Mirror only semantically directional visuals.

Do not solve overflow by unreadably shrinking text.

Return risky layouts and exact resilient behavior.
