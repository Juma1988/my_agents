# Kira Flutter Widget Testing

Use widget tests for UI behavior with real regression value.

Good candidates:
- form validation;
- button enabled/disabled state;
- loading/error/empty rendering;
- interaction events;
- semantic labels;
- reusable component states;
- text scaling/overflow-sensitive components.

Avoid testing Flutter framework internals.

Prefer deterministic pumping/waiting over arbitrary delays.

Verify visible behavior and important semantics, not implementation-private widget trees.
