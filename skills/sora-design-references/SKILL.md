# Sora Design References

Reference source: <https://github.com/HagiCode-org/awesome-design-md-site>.

Use this source to compare design-system patterns and document the rationale for a design choice. It is a reference, not a component library and not a mandate to copy its visual language.

1. Start with the product's existing design language and user needs.
2. Consult only relevant examples.
3. Extract transferable principles, not a copied interface.
4. Check accessibility, responsive behavior, and platform fit before recommending a pattern.
5. Return the source URL and the specific principle used.

Do not use this reference to override approved product direction.
