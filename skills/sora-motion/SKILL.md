# Sora Motion

Motion must explain or confirm something.

Use motion for:
- state continuity;
- feedback;
- hierarchy;
- spatial relationship;
- success/error acknowledgement;
- perceived responsiveness.

For each meaningful motion define:
- trigger;
- purpose;
- duration class;
- easing character;
- interruption behavior;
- reduced-motion alternative.

Avoid:
- long blocking animation;
- motion on every tap;
- animation that delays task completion;
- decorative movement competing with content.

Prefer subtle, interruptible motion.
