# Rei Version & Build

Verify:
- semantic/product version policy;
- Android versionCode/build number;
- iOS build number;
- flavor/environment;
- package/bundle IDs;
- release endpoints;
- debug flags;
- artifact path.

Use established project conventions.

Record release build command and artifact checksum when useful.

Never substitute a debug build for a release artifact.
