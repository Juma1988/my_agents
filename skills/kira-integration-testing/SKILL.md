# Kira Integration Testing

Use when evidence requires multiple real boundaries.

Prioritize:
- authentication journey;
- core creation/edit/save flow;
- persistence after restart;
- critical navigation;
- permission-dependent journey;
- destructive operations;
- release-critical smoke path.

Keep scenarios few and valuable.

Record environment/device and exact revision.

Do not create a huge E2E suite for behavior already proven cheaply at lower levels.
