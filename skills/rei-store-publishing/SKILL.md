# Rei Store Publishing

Use only after explicit authorization.

Verify:
- target store;
- app identity;
- release channel/track;
- visibility;
- version/build;
- artifact;
- required metadata;
- rollout mode;
- authoritative result.

Do not infer permission to release publicly from permission to build.

After publication, verify the store/deployment destination rather than trusting CLI success alone.
